# Проблемы

### Сценарий 1

1. Администратор сохраняет в незашифрованном excel файле.
2. Администратор может случайно или намеренно повредить данные других пользователей
3. excel файл неудобен при работе с ним несколькими администраторами - данные могут пропасть
4. excel файл никак не защищён от копирования и перемещения
5. Администратор сохраняет файлы пользователя в разных форматах - данные могут пропасть
6. Файлы хранятся в незашифрованном виде
7. Администратор может повредить или отредактировать случайно файлы другого пользователя

### Сценарий 2

1. Администратор должен найти пациента и потом его записать руками в другой системе. Он может записать не того пациента
2. Администратор может повредить список при записи времени визита.
3. Доктор имеет доступ с писку других врачей
4. Доктор имеет неограниченный доступ к файлам всех пользователей: может повредить, читать любые документы, подменить

### Сценарий 3

1. Доктор имеет доступ к анализам всех пользователей: может повредить
2. Доктор имеет доступ к анализам всех пользователей: найти анализы не того пользователя
3. Анализы в незашифрованном виде
